# Shomolu Emergency Healthcare Accessibility

**Research Question:**  
Which residential areas in Shomolu LGA are more than 2 km from the nearest emergency healthcare facility?

**Why It Matters:**  
To identify residential areas with limited access to emergency healthcare and support better healthcare planning.

**Study Area:**  
Shomolu LGA, Lagos State, Nigeria.

## Datasets

- **Ward Boundaries — GRID3:** https://grid3.org/geospatial-data-nigeria
- **Road Network — OSM via QuickOSM:** https://www.openstreetmap.org
- **Healthcare Facilities — OSM via QuickOSM / Google Earth Pro:** https://www.openstreetmap.org
- **Residential Areas — OSM via QuickOSM:** https://www.openstreetmap.org

## Method

Map residential areas and emergency healthcare facilities, calculate the distance to the nearest facility using the road network, and identify areas **more than 2 km** away.

## Output

A map showing residential areas more than 2 km from the nearest emergency healthcare facility.
